混合模式：前后端分工

数据 来源 说明
楼号 1-100 🤖 前端生成 Array.from({length:100},(_,i)=>i+1)
单元 1-5 🤖 前端生成 固定 1-5，大卡片展示
房号规则 🤖 前端生成 每层 101-104, 201-204...
格式：(楼层)(0)(序号)
已占用房号 🔌 API 标记 🆕 需新增 API
GET /api/masterdata/rooms/occupied?community_id=&building=&unit=

房号生成规则

楼层 f ∈ [1, N]（N 由小区配置决定，默认 30）
每层 4 户：01, 02, 03, 04
房号 = f × 100 + 序号

1层: 101 102 103 104
2层: 201 202 203 204
3层: 301 302 303 304
...

Phase 1（快速上线）vs Phase 2

Phase 1 — 纯前端

  • 楼号 1-100、单元 1-5、房号前端生成
  • 不区分已占用，所有房号可选
  • 提交时后端校验唯一性
  • 0 新 API，改 join-community.vue 即可

Phase 2 — +API 标记

  • 新增 occupied rooms API
  • 房号网格中「已住」标签灰显不可选
  • 可扩展：楼栋总层数由小区主数据配置
  • 需主数据服务 + user-service 配合
