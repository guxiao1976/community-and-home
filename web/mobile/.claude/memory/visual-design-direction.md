# 视觉设计方向

"白色为主，淡咖色点缀，给人温暖、简单、松弛的感觉"

## 配色速查

| 角色 | 色值 | 示例 |
|------|------|------|
| 页面背景 | `#FFFFFF` 纯白 | 大面积留白 |
| 卡片/区块 | `#FAF8F5` 暖白 | 圆角卡片 |
| 输入框 | `#F5F0EA` 暖灰白 | 柔和边界 |
| 主色调（按钮/选中/链接） | `#B8956A` 温暖咖 | 克制使用 |
| 深浅咖 | `#D4B896` / `#8B6F4E` | hover/按下 |
| 主文字 | `#3D3226` 暖深棕 | 比纯黑柔和 |
| 辅助文字 | `#A6988A` 暖灰 | 不抢眼 |
| 边框分割线 | `#E8E0D5` 暖色 | 轻盈 |

## 原则

- **白色为主**：页面和卡片大面积白色，用阴影和边框而非色块区分层次
- **咖色克制**：仅在按钮、Tab选中态、链接等关键交互处使用，不做大面积咖色背景
- **圆角柔和**：卡片 12rpx、按钮 48rpx 胶囊形
- **留白充足**：页面边距 32rpx，卡片内边距 24-32rpx
- **阴影轻盈**：不厚重，只微微浮起

## 相关文件

- `src/uni.scss` — 全局 SCSS 变量定义
- `docs/design.md` — 完整设计文档
- `src/pages.json` — 导航栏/TabBar 配色

**Why:** 保持移动端视觉一致性的核心参考，所有页面开发以此为准。

**How to apply:** 新增页面时优先使用 uni.scss 中定义的变量，不自定义硬编码颜色。如需新颜色，先评估是否可用现有变量替代。
