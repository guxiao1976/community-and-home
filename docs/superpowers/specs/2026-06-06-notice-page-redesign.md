# 公告信息页面重设计 — 设计文档

## 概述

重新设计移动端公告信息页面 `pages/notice/notice.vue`，提升视觉品质至登录页同等水平，并增强小区切换交互。

### 设计目标

- 视觉品质对齐登录页、加入小区页
- 温暖社区风格：柔和渐变头部、咖色点缀、大面积留白
- 小区切换器改用自定义下拉面板（替代系统 ActionSheet）
- 加入骨架屏加载、空状态插画

## 色彩与主题

遵循 `docs/design.md` 色彩体系：
- 主色: `#B8956A`（温暖咖色）
- 文字: `#3D3226`（暖深棕）、`#5D5348`（深灰，电话号）、`#A6988A`（辅助灰）
- 背景: `#FFFFFF`（页面）、`#FAF8F5`（卡片）
- 边框: `#E8E0D5`

角色颜色映射（通知左边条 + 标签）：
- 社区(1): `#B8956A`
- 业委会(2): `#8DAF7E`
- 物业(3): `#D4958A`
- 网格员(4): `#E8C98E`

## 交互增强

### 骨架屏加载

首次进入页面时，显示骨架屏占位：
- 头部：圆角矩形（模拟切换器）
- 通知区：3 行带左边条的矩形
- 联络区：2×2 网格矩形
- 寻失区：2 个横向卡片矩形

数据加载完成后，骨架屏渐隐，内容渐显。

### 空状态插画

每个板块无数据时显示友好空状态：
- 通知公告："📭 暂无通知公告"
- 便民联络："📞 暂无联络信息"
- 寻失互助："🔍 暂无寻失信息"

使用 emoji + 浅灰文字，居中显示，带 48rpx 上下边距。

### 下拉刷新

页面支持 `onPullDownRefresh`，下拉时重新加载所有数据，刷新完成后停止动画。

## 数据流

```
pages/notice/notice.vue
  ├─ communityStore.loadMemberships()  → 加载小区列表
  ├─ communityStore.currentCommunityId → 监听切换
  ├─ getNoticeList(cid)    → notices[]
  ├─ getContacts(cid)      → contacts[] → contactGroups (computed)
  ├─ getLostFoundList(cid) → lostFoundItems[]
  └─ 广告数据（预留，当前硬编码占位）
```

不再需要 greeting 逻辑和 userStore.nickname。
