### [真实 bug 修复] 运维验证暴露

1. **`model/content_post.go` Insert SQL 漏 `published_at` 列**：submit 逻辑层已置 PublishedAt 但未落库 → published_at 恒 NULL → 跑马灯（`published_at >= since`）恒空。补列 + 回归测试 `TestContentPostModel_Insert_SubmitWritesPublishedAt`
2. **`kafkapush/producer.go` Push 阻塞发布**：用 RPC 请求 ctx 同步写，Kafka 不可用时 kafka-go 重试耗尽请求 deadline → 客户端 DeadlineExceeded（帖实际已提交）。修复：网络写走 `context.WithTimeout(Background, 3s)` 独立超时，DB 落标走请求 ctx
