## 关键变更

### [Harness] 冒烟脚本 reflection 适配修复

- **问题**：`harness-smoke.sh` 用 grpcurl 无 proto 直调，但 go-zero 服务默认无 gRPC reflection → L2 全失败
- **修复**：SMOKE_MATRIX 加 proto 列，grpcurl 带 `-import-path api-proto/api -proto` 直调；修正 auth/file/masterdata 的冒烟方法（ValidateToken/GetUploadUrl/GetDivision）；连通性判据改为「服务可达即 PASS」（业务错误码不算 FAIL）
- **效果**：L2 0/8 → 8/8

### [Common] configx 支持 ${VAR:default} 语法（ai-model 启动修复）

- **问题**：`os.ExpandEnv` 不认 `${VAR:default}`，把 `:default` 当变量名，未设置时替换为空 → `Host: :` 坏行 → ai-model YAML 解析崩溃无法启动
- **修复**：configx 新增 `expandEnv` 支持 `${VAR}` 与 `${VAR:default}`（未设置用默认值），向后兼容
- **效果**：ai-model-service 正常启动（8080 + etcd 注册）
