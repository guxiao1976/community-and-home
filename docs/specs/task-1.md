# 这是一个检查修改现有微服务的任务。
## 任务
- 检查项目微服务，各微服务rpc功能是否合理，各微服务之间的rpc接口是否匹配。
- 检查微服务配套的数据库是否和微服务匹配，数据库中的表设计是否合理。
- 前期，把identity微服务功能给划分给了 auth和user，这个identity需要去掉，但是目前前端web/pc下面大量引用了其http网关，需要把相关网关在auth和user中实现，需要科学决策放在哪个中合适。

- 数据库等中间件的用户名密码 参考 code 目录下的docker-compose.yml文件。
