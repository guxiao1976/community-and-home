# P0: rel_user_role 生命周期三列缺建库 SQL（从零建库 1054）

## 问题

permission-service 的 rel_user_role 表 Go 模型依赖 status/verified_at/expires_at 三列（INSERT/BatchInsertUserRoles 显式写入），但仓库无任何迁移创建它们——migration/ 仅 001(唯一索引)+002(platforms)，全仓唯一建表 docs/specs/migration.sql:224-236 缺三列且为 AUTO_INCREMENT/created_time 旧结构。从零建库报 MySQL 1054。修复：新增 003_add_role_lifecycle.sql（information_schema 幂等 guard + status TINYINT NOT NULL DEFAULT 2 由 ALTER-DEFAULT 自动回填存量、verified_at/expires_at DATETIME NULL）；同步修 migration.sql（补三列/created_at/索引名 uk_user_role_scope，id 保留自增——评审发现去自增会断裂省略 id 的 INSERT）；验证 init_permissions.sql:238 从零建库可执行。注：已设计评审（3 轮意见已吸收），spec 产物在 .harness/changes/rel-user-role-migration-publish-fix/。
