# update_pipeline_logic 恒真条件修复

## 问题

`api/internal/logic/pipeline/update_pipeline_logic.go:52,58` 中：
```go
if req.SmallModelConfigKey != "" || req.SmallModelConfigKey == ""
```
和
```go
if req.LargeModelConfigKey != "" || req.LargeModelConfigKey == ""
```
条件恒为 true——不管什么值都会执行赋值。这意味着即使请求未提供 `small_model_config_key` 字段（空字符串），仍会用空字符串覆盖已有值，导致该字段被意外清空。这与其他字段的"非空才更新"语义矛盾。

## 完成标准

- [ ] 删除 `|| req.SmallModelConfigKey == ""` 和 `|| req.LargeModelConfigKey == ""` 部分
- [ ] 仅保留 `!= ""` 判断（空值不覆盖已有值）
- [ ] 验证：不传 `small_model_config_key` 时，已有值不被清空
- [ ] 验证：传了 `small_model_config_key` 时，正确更新
- [ ] `go build ./...` 通过
- [ ] `go test ./...` 通过
