# 软删除后清除 ModelManager adapter 缓存

## 问题

`rpc/internal/logic/deletemodelconfiglogic.go:41` 中 `DeleteModelConfigLogic` 直接调用 `l.svcCtx.ModelConfigModel.Update()` 进行软删除，未通过 `ModelManager.DeleteModelConfig()`（后者会调用 `InvalidateCache` 清除 adapter 缓存）。
`ModelManager` 的 adapter 缓存中可能保留已删除模型的旧 adapter，影响后续健康检查调度。

## 完成标准

- [ ] 软删除后调用 `l.svcCtx.ModelManager.InvalidateCache(in.Id)` 清除缓存
- [ ] 或统一通过 `ModelManager.DeleteModelConfig()` 执行删除
- [ ] `go build ./...` 通过
- [ ] `go test ./...` 通过
