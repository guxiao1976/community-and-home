# PipelineId path 参数解析修复

## 问题

`api/internal/types/types.go` 中 `DeletePipelineReq`、`GetPipelineReq`、`ActivatePipelineReq` 的 `PipelineId` 字段使用 `json:"pipeline_id"` tag。
但路由定义为 `DELETE /pipeline/:pipeline_id`、`GET /pipeline/:pipeline_id`、`PUT /pipeline/:pipeline_id/activate`（path 参数）。
go-zero 的 `httpx.Parse` 根据 tag 区分来源：path 参数需要 `path` tag，`json` tag 用于 body 解析。
当前 `json` tag 不会提取 path 参数，导致 DELETE/GET 请求中 `pipeline_id` 为空值。

## 完成标准

- [ ] 将 `DeletePipelineReq.PipelineId` tag 改为 `path:"pipeline_id"`
- [ ] 将 `GetPipelineReq.PipelineId` tag 改为 `path:"pipeline_id"`
- [ ] 将 `ActivatePipelineReq.PipelineId` tag 改为 `path:"pipeline_id"`
- [ ] 验证 DELETE/GET/PUT 请求能正确提取 path 参数
- [ ] `go build ./...` 通过
- [ ] `go test ./...` 通过
