# activate_pipeline 竞态修复

## 问题

`api/internal/logic/pipeline/activate_pipeline_logic.go:26-35` 中 Activate 逻辑：
1. 先查所有 pipeline（limit 1000）
2. 再逐个 Update 将 `is_production` 设为 0
3. 最后设置目标为 1

存在竞态：如果并发调用，两个 pipeline 可能同时被设为 `is_production=1`。且未使用事务，逐条 Update 在部分失败时不回滚。

## 完成标准

- [ ] 使用 DB 事务包裹整个 activate 操作
- [ ] 用 `WHERE is_production=1` 条件批量更新替代逐条循环
- [ ] 事务内执行：`BEGIN; UPDATE ... SET is_production=0 WHERE is_production=1; UPDATE ... SET is_production=1 WHERE pipeline_id=?; COMMIT;`
- [ ] 部分失败时正确回滚
- [ ] `go build ./...` 通过
- [ ] `go test ./...` 通过
