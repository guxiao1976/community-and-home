# pipeline handler 响应格式统一为 responsex.Response

## 问题

`api/internal/handler/pipeline/` 下 7 个 handler 使用 `httpx.OkJson(w, resp)` / `httpx.Error(w, err)` 返回响应。
其他 handler（health、text_check、image_check、submit_review）和 middleware 都已使用 `responsex.Response`。
这导致 pipeline 端点响应格式与项目其他端点不一致：其他端点返回 `{code, msg, data}` 标准格式，pipeline 端点返回原始 JSON。

## 完成标准

- [ ] 7 个 pipeline handler 统一使用 `responsex.Response(w, resp, err)` 替代 `httpx.OkJson`/`httpx.Error`
- [ ] Logic 层适配为返回 `(*T, error)` 形式（当前 Create/Update/Delete/Activate 返回 error 无 data）
- [ ] 响应格式与其他端点一致：`{code, msg, data}`
- [ ] `go build ./...` 通过
- [ ] `go test ./...` 通过
- [ ] `harness-checks.sh --service moderation-service` check #13 (response_wrap) PASS
