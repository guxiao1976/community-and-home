# 评审补 subagent 层 + 统一三层 agent 引用（架构一致性债务）

## 问题

架构分层漂移：需求分析（requirement-analyst.md + requirement-analysis.md）和架构设计（architecture-designer.md + architect-design.md）都有 subagent+skill 两层，但需求评审只有 skill（review.md），缺 subagent 层。且 workflow 三处 agent 入口引用不一致：架构设计师引 subagent（spec-pipeline.js:793），需求分析师引 skill（:532），评审引 skill（:659/:827）。review.md 把「角色权限/服务名映射/工具熔断」等角色层内容硬塞进了 skill。\n\n方案 A（推荐）：明确 subagent=角色层（我是谁/上下文加载清单/熔断/完成通知/交接），skill=流程层（SOP/视角/报告格式）。①新建 .harness/agents/subagents/reviewer.md；②review.md 瘦身（抽走角色层内容）；③workflow 三处统一为「先 Read <subagent>.md，subagent 内部再 Skill('<skill>')」，对齐 architecture-designer 现状。
