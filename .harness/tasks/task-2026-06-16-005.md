# gRPC 客户端超时配置

## 问题

`rpc/etc/moderation.yaml` 中：
- gRPC 服务 Timeout: 30000（30 秒）
- `AiModelRpc` 和 `MasterDataRpc` 未显式配置 Timeout 值
- 大模型调用可能需要 60s+，当前超时链不满足最长调用需求

记忆 `grpc-timeout-layers` 要求：REST > gRPC client > external，三层超时需对齐。

## 完成标准

- [ ] 在 `AiModelRpc` 中显式设置 `Timeout: 60000`（60 秒，对齐大模型调用）
- [ ] API 层 Timeout 检查 ≥ 60s（确保外层不先超时）
- [ ] PipelineExecutor 通过 gRPC 调用 ai-model-service 时使用独立 Context（带超时）
- [ ] `go build ./...` 通过
- [ ] `go test ./...` 通过
