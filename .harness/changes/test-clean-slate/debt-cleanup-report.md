### 债务 2: 配置文件默认密码 ✅

**问题**: 配置文件包含默认密码 `root123456`

**文件**:
1. `api/etc/masterdata-api.yaml` (第 6 行)
2. `rpc/etc/masterdata.yaml` (第 10 行)

**安全风险**:
- 生产环境若未设置 `MYSQL_PASSWORD`，将使用弱密码
- 违反项目编码规范 §7（密钥在 .env 管理）

**修复前**:
```yaml
DataSource: ${MYSQL_USER:root}:${MYSQL_PASSWORD:root123456}@tcp(...)
```

**修复后**:
```yaml
DataSource: ${MYSQL_USER}:${MYSQL_PASSWORD}@tcp(...)
```

**影响**:
- ✅ 移除默认值
- ✅ 强制要求环境变量
- ✅ 符合安全最佳实践

**部署注意**:
- 必须在 .env 中设置 `MYSQL_USER` 和 `MYSQL_PASSWORD`
- 否则服务启动时会报错（这是预期行为）

### 债务 3: Outbox 非事务性写入（P1）

**问题**: `reviewItemLogic.go:113` Outbox 写入在事务外

**根因**: 
```go
// 当前实现（错误）
Update(entity)           // 事务内
WriteOutboxMessage(...)  // 事务外，返回值被忽略
```

**风险**: 
- 实体已更新但 outbox 写入失败 → 数据不一致
- 事件丢失

**修复建议**:
```go
// 正确实现
tx.Begin()
tx.Update(entity)
tx.WriteOutboxMessage(...)  // 在同一事务内
tx.Commit()
```

**工作量**: 1-2 小时
- 需要重构审批状态变更逻辑
- 需要测试事务回滚场景

**建议**: 作为独立任务处理（高优先级）
