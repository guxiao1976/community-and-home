### 交付成果
1. ✅ 新增 `check_memory_index()` 函数
   - 检查索引文件存在性
   - 比较索引生成时间和最新记忆文件修改时间
   - 索引过期 → FAIL 并提示修复命令

2. ✅ 集成到 `harness-checks.sh`
   - 作为 Check #16 运行
   - 在 main() 中调用

3. ✅ 修复脚本错误
   - 修复 labels unbound variable 问题

### 实现逻辑
```bash
# Check 16: Memory Index Freshness
1. 检查索引文件存在: .harness/knowledge/memory/.memory-index.json
2. 提取索引生成时间: jq -r '.generated_at'
3. 查找最新记忆文件修改时间: find -printf '%T@'
4. 比较时间戳:
   - newest_memory > index → FAIL "索引过期"
   - newest_memory ≤ index → PASS "索引最新"
```
