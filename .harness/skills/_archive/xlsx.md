# XLSX 技能使用模板

## 技能名称
`xlsx`

## 功能描述
生成和处理 Excel 电子表格，支持多工作表、公式、图表、条件格式等高级功能。

## 使用场景
- 生成测试报告（单元测试、E2E 测试）
- 导出数据分析结果
- 创建 API 清单
- 生成工作量统计表
- 导出配置管理表
- 生成项目进度跟踪表

## 输入要求

### 必需信息
- 数据内容（表格数据）
- 工作表名称
- 列定义

### 可选信息
- 表头样式
- 条件格式
- 数据验证
- 公式计算
- 图表
- 冻结窗格

## 输出内容
1. Excel 文件 (.xlsx)
2. 多个工作表（如需要）
3. 格式化的表格
4. 数据图表（可选）

## Excel 要求

生成包含 5 个工作表的测试报告：

### 工作表1: 测试概览
- 服务信息（名称、版本、日期）
- 测试判定（大字体，PASS 绿色 / FAIL 红色）
- 统计数据（卡片式布局）
  - 总测试用例数
  - 通过数（绿色）
  - 失败数（红色）
  - 跳过数（黄色）
  - 总体覆盖率（进度条）

### 工作表2: 单元测试明细
表格格式：
- 列: 测试包、测试用例、结果、执行时间、覆盖率
- 表头: 加粗、背景色 #4472C4、白色字体
- 结果列: ✓ 绿色，✗ 红色
- 覆盖率列: 条件格式（>80% 绿色，60-80% 黄色，<60% 红色）
- 冻结首行
- 自动筛选

### 工作表3: E2E 测试明细
表格格式：
- 列: 测试场景、测试步骤、预期结果、实际结果、结果、耗时
- 格式同工作表2

### 工作表4: 覆盖率分析
- 表格: 按包统计覆盖率
- 图表: 柱状图展示各包覆盖率
- 条件格式: 覆盖率色阶

### 工作表5: 趋势分析（如有历史数据）
- 折线图: 覆盖率趋势
- 柱状图: 测试用例数量趋势

## 格式要求
- 列宽自动调整
- 数字右对齐，文本左对齐
- 表头加粗、居中
- 边框: 所有单元格
- 冻结窗格: 首行
- 数据验证: 结果列只能是 ✓ 或 ✗

输出文件: permission-service-test-report-2026-06-21.xlsx

## 最佳实践

### 1. 表格设计
```
清晰的表头:
- 第一行: 表头
- 加粗、背景色、居中
- 冻结首行

数据区域:
- 边框清晰
- 交替行颜色（可选）
- 数据类型一致
```

### 2. 条件格式
```
按值着色:
- >80: 绿色
- 60-80: 黄色
- <60: 红色

按规则:
- PASS: 绿色背景
- FAIL: 红色背景
- WARNING: 黄色背景
```

### 3. 公式使用
```excel
=SUM(B2:B10)           // 求和
=AVERAGE(B2:B10)       // 平均值
=COUNTIF(C2:C10,"✓")   // 计数
=IF(B2>80,"优秀","良好") // 条件
```

### 4. 图表选择
- **柱状图**: 比较不同类别
- **折线图**: 展示趋势
- **饼图**: 占比分析
- **散点图**: 相关性分析

### 5. 数据验证
```
下拉列表:
- 状态: 完成/进行中/待开始
- 结果: ✓/✗

数值范围:
- 覆盖率: 0-100
- 工时: >0
```

## 注意事项

### 1. 性能考虑
- 大数据集（>10000 行）考虑分页
- 避免过多的条件格式规则
- 图表数量适中（< 10 个/工作表）

### 2. 兼容性
- 使用标准 Excel 功能
- 避免宏（VBA）
- 测试在不同 Excel 版本

### 3. 文件大小
- 压缩图片
- 避免嵌入大量外部对象
- 删除隐藏的数据和格式

### 4. 数据安全
- 敏感数据加密工作表
- 设置密码保护
- 限制编辑范围

### 5. 可维护性
- 使用命名范围
- 公式简洁易懂
- 添加注释说明

## 常见问题

### Q: 如何处理大量数据？
A: 使用数据透视表汇总，分页展示，或导出为 CSV。

### Q: 公式不自动计算怎么办？
A: 检查计算选项，确保设置为"自动计算"。

### Q: 图表不显示怎么办？
A: 检查数据范围，确保数据有效，图表类型合适。

### Q: 如何合并单元格？
A: 谨慎使用合并单元格，可能影响排序和筛选。

### Q: 如何设置打印区域？
A: 在 prompt 中指定打印区域和分页符。

## 输出格式说明

### 文件命名
```
{服务名}-{报告类型}-{日期}.xlsx

示例:
- permission-service-test-report-2026-06-21.xlsx
- api-list-2026-06.xlsx
- workload-2026-06.xlsx
```

### 工作表命名
- 简洁明了（< 20 字符）
- 中文或英文
- 避免特殊字符

### 单元格格式
- 文本: 左对齐
- 数字: 右对齐
- 日期: 统一格式 YYYY-MM-DD
- 百分比: 保留 1-2 位小数
