# qwen2.5:3b 不适合内容审核初筛

## 现象

用 qwen2.5:3b 做审核管线小模型初筛，对 8 个测试用例全部返回 unsafe（置信度 70-80%），包括"毛泽东是伟大领袖"（赞美）、"加微信聊聊工作"（正常社交）等明显安全的内容。起不到任何过滤作用——每个 AC 命中都会进入大模型，白白浪费 3-5 秒本地推理时间。

## 原因

3B 参数级别模型不具备充分的语义理解能力。看到敏感关键词（如"毛泽东"、"微信"）后，出于安全保守策略一律判 unsafe，无法区分上下文中的赞美/中性引用/攻击/广告。

## 结论

- **不要用 3B 级别模型做任何需要语义判断的任务**
- 审核架构已从三层（AC→小模型→大模型）简化为两层（AC→大模型）
- 如需恢复小模型层，至少用 7B+ 模型（qwen2.5:7b / qwen3:8b）
